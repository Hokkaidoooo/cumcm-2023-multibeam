# 2023 数学建模国赛 B 题：多波束测线问题

2023 年全国大学生数学建模竞赛（CUMCM）B 题的三人团队参赛作品，包含论文、四问求解代码、历史表格和图形。模型围绕坡面水深、条带覆盖宽度、相邻重叠率与测线方向展开。

等深线沿用仓库的[历史成果](code/问题四/等深线图.png)；声束、覆盖带与测线为概念示意。参赛时的[测线布设原图](code/问题三/测线布设示意图.png)保留供对照。

## 四问分别做什么

| 问题 | 方法与目标 | 代码和历史结果 |
| --- | --- | --- |
| 一 | 根据坡度与水深计算覆盖宽度和重叠率 | [question1.py](code/问题一/question1.py) · [result1.xlsx](code/问题一/result1.xlsx) |
| 二 | 分析测线方向改变后的有效坡度与覆盖宽度 | [question2.py](code/问题二/question2.py) · [result2.xlsx](code/问题二/result2.xlsx) |
| 三 | 在矩形海域生成测线位置，目标是兼顾覆盖与总长度 | [question3.py](code/问题三/question3.py) · [测线位置](code/问题三/测线距最西边距离.xlsx) |

## 历史数值与适用范围

- 问题三现有脚本输出 **32 条测线、总长度 118 528 米**。
- 问题四现有脚本输出总长度约 **243 033 米**。

这些是现有方案的计算值，不构成全覆盖验证或全局最优性证明。论文原稿保留竞赛时的表述，阅读时请结合下面的复现差异。

## 运行与输入输出

问题三仅依赖 Python 标准库，可从仓库根目录查看现有方案输出：

```sh
python code/问题三/question3.py
```

其余脚本没有统一的命令行入口，运行前需要明确工作目录和输出位置：

| 脚本 | 输入或依赖 | 输出注意事项 |
| --- | --- | --- |
| 问题一、二 | Python、`openpyxl`；各自目录中的历史结果工作簿 | 会保存到原 `result1.xlsx` / `result2.xlsx`，应在独立副本中运行 |
| 问题四的 Python 脚本 | 按脚本需要安装 `pandas` 等依赖，核对地形数据路径 | [附件数据处理.py](code/问题四/附件数据处理.py) 沿用本地绝对路径，缺原始附件时无法完整复现 |
| 问题四的 `.m` 文件 | MATLAB 与脚本指定的处理数据 | 分别用于地形、等深线与测线图形，尚未完成新环境复跑 |
| 灵敏度分析 | Python、`pandas`、XLSX 写出引擎（如 `openpyxl`） | 写入 `output.xlsx`，不会直接更新已有的 `灵敏度分析.xlsx` |

后续首先补充独立的覆盖与重叠率验算，再追踪历史差异、统一参数与输出路径。比较方案长度前，需要先确认它满足几何约束。
